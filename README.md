# VERA
VERA (Vision for Enhanced Robotic Automation) is a low-cost, vision-guided automation framework that integrates computer vision with robotic control to enable intelligent pick-and-place workflows. The system uses camera-based perception and homography-based calibration to map pixel coordinates to real-world positions, allowing accurate object detection and manipulation.

Designed for accessibility and flexibility, VERA enables the calibration and storage of pick positions, as well as the automation of repetitive tasks without requiring advanced programming knowledge.

This project aims to empower SMEs by providing an affordable and scalable solution for robotic automation, bridging the gap between advanced manufacturing technologies and real-world industrial adoption.
